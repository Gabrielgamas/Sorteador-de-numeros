# Sorteador de Números

## Descrição
Este é um projeto de sorteador de números online e gratuito. O usuário pode definir um intervalo de números, escolher a quantidade desejada e optar por permitir ou não a repetição de números no sorteio.

## Tecnologias Utilizadas
- **HTML**: Estrutura da página
- **CSS**: Estilização da interface
- **JavaScript**: Lógica de funcionamento do sorteador

## Estrutura do Projeto
```
/
├── index.html  # Estrutura do site
├── styles/
│   ├── styles.css  # Arquivo de estilos
├── script.js  # Lógica do sorteio
├── assets/

│   ├── roll.svg  # Ícone do botão de sortear
│   ├── reroll.svg  # Ícone do botão de sortear novamente
│   ├── chat.svg  # Ícone de chat nas perguntas
```

## Como Funciona
1. O usuário insere a quantidade de números a serem sorteados.
2. Define o intervalo de valores (mínimo e máximo).
3. Escolhe se deseja permitir números repetidos.
4. Clica no botão **"Sortear"** para gerar os números.
5. O resultado é exibido na tela.
6. O usuário pode clicar em **"Sortear Novamente"** para reiniciar o processo.

## Funcionalidades
- Gera números aleatórios dentro de um intervalo definido pelo usuário.
- Opção de não permitir repetição de números.
- Interface responsiva e intuitiva.
- Botão para refazer o sorteio rapidamente.

## Como Executar o Projeto
1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador.
